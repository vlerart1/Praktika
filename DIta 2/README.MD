Praktika e Parë në Git

Ky është hapi i parë i praktikës time në Git dhe GitHub.    

Gjatë kësaj praktike do të mësoj konceptet bazë të Git-it, si krijimi i një repository, ruajtja e ndryshimeve, përdorimi i commit-eve dhe menaxhimi i versioneve të projektit.

Qëllimi

Qëllimi i kësaj praktike është të kuptoj se si funksionon Git dhe si përdoret për të menaxhuar dhe ruajtur ndryshimet në një projekt.

Çfarë do të mësoj
Krijimin e një repository.
Shtimin dhe ndryshimin e skedarëve.
Përdorimin e git add.
Krijimin e commit-eve me git commit.
Publikimin e projektit në GitHub.
Menaxhimin e versioneve të projektit.

Ky repository do të përdoret për të dokumentuar hapat dhe ushtrimet e praktikës në Git.
Në hapat e ardhshëm do të praktikoj më shumë komanda dhe mënyra të ndryshme të përdorimit të Git-it.

Praktika e Dytë në Git

Kjo është dita e dytë e praktikës time në Git dhe GitHub.

Gjatë kësaj praktike do të vazhdoj të mësoj më shumë rreth përdorimit të Git-it dhe mënyrës se si menaxhohen ndryshimet në një projekt. Pas njohjes me konceptet bazë në ditën e parë, tani do të praktikoj më shumë komanda dhe do të kuptoj më mirë procesin e ruajtjes së ndryshimeve.

Qëllimi

Qëllimi i kësaj dite është të përforcoj njohuritë e fituara në praktikën e parë dhe të mësoj si të kontrolloj gjendjen e repository-t, të shoh ndryshimet dhe të menaxhoj commit-et.

Çfarë do të mësoj
Përdorimin e komandës git status.
Kontrollimin e ndryshimeve në skedarë.
Përdorimin e komandës git diff.
Shtimin e ndryshimeve me git add.
Krijimin e commit-eve me git commit.
Shikimin e historikut të commit-eve me git log.
Kontrollimin e versioneve të mëparshme të projektit.
Publikimin dhe përditësimin e ndryshimeve në GitHub me git push.
Praktika

Gjatë ditës së dytë do të bëj disa ndryshime në skedarët e projektit dhe më pas do të kontrolloj gjendjen e repository-t. Do të përdor git status për të parë skedarët që janë ndryshuar dhe git diff për të parë konkretisht se çfarë ndryshimesh janë bërë.

Pas kontrollimit të ndryshimeve, do t'i shtoj ato në staging area duke përdorur git add dhe më pas do t'i ruaj me një commit të ri duke përdorur git commit.

Në fund, do të përdor git log për të parë historikun e commit-eve dhe git push për të dërguar ndryshimet në repository-n tim në GitHub.

Përfundim

Dita e dytë më ndihmon të kuptoj më mirë ciklin bazë të punës me Git: ndryshimi i skedarëve → kontrollimi i ndryshimeve → git add → git commit → git push.

Në ditët e ardhshme do të vazhdoj të praktikoj komanda të tjera dhe do të mësoj më shumë rreth branch-eve, bashkimit të ndryshimeve dhe mënyrave të bashkëpunimit me GitHub.
