Praktika e Parë në Git

Ky është hapi i parë i praktikës time në Git dhe GitHub.

Gjatë kësaj praktike do të mësoj konceptet bazë të Git-it, si krijimi i një repository, ruajtja e ndryshimeve, përdorimi i commit-eve dhe menaxhimi i versioneve të projektit.

Qëllimi

Qëllimi i kësaj praktike është të kuptoj se si funksionon Git dhe si përdoret për të menaxhuar dhe ruajtur ndryshimet në një projekt.

Çfarë do të mësoj
Krijimin e një repository.
Shtimin dhe ndryshimin e skedarëve.
Përdorimin e git add.
Krijimin e commit-eve me git commit.
Publikimin e projektit në GitHub.
Menaxhimin e versioneve të projektit.

Ky repository do të përdoret për të dokumentuar hapat dhe ushtrimet e praktikës në Git.
